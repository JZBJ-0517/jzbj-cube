# Obsidian 节点工作流

可视化工作流编排插件。在画布上拖拽节点、连线流转 Markdown，AI 驱动内容变换。

![](https://img.shields.io/badge/version-1.0.0-blue)
![](https://img.shields.io/badge/Obsidian-1.0.0%2B-purple)

## 设计思路

Obsidian 的 vault 里堆着大量笔记、知识、Skill 文件。手动翻找、拼接、处理效率太低。

这个插件做一件事：**把你脑子里的信息处理流程直接画出来**。左边的节点读文件，中间的节点走 AI 变换，右边的节点写回 vault。每个节点只做一件事，连线就是数据流向。

## 12 个节点

### 数据输入/输出 (I/O)

| 节点 | 说明 |
|------|------|
| **Markdown 输入** | 从 vault 读取 Markdown 文件 |
| **Markdown 输出** | 处理结果写回 vault 指定目录 |
| **Canvas 输入** | 读取 .canvas 文件，提取文本和引用文件 |
| **文本** | 手写文本或接收上游，双路自动合并 |
| **知识库** | 按文件/标签/文件夹批量采集，支持 BM25 索引 |

### AI 变换 (Transform)

| 节点 | 说明 |
|------|------|
| **Skill** | 加载 Skill 文件作为系统提示，AI 变换输出，三路输入（内容+知识+记忆） |
| **AI 输出** | 卡片上直填提示词，AI 生成 |
| **条件路由** | AI 多条件匹配，命中后按分支输出 |
| **记忆** | AI 自动提取值得长期记忆的信息，存入 vault；支持 BM25 检索+时效衰减 |

### 子流程

| 节点 | 说明 |
|------|------|
| **子流程** | 将整个工作流封装为一个可复用节点 |
| **子流程输入/输出** | 定义子流程的端口 |

## 安装

### 手动安装

1. 下载最新 Release 中的 `main.js`、`manifest.json`、`styles.css`
2. 放入 vault 的 `.obsidian/plugins/jzbj-cube/` 目录
3. 设置 → 第三方插件 → 启用

### BRAT 安装

在 BRAT 中添加此仓库地址即可自动更新。

## 使用

1. 点击左侧 Ribbon 的方块图标打开工作流面板
2. 从左侧节点列表拖拽节点到画布
3. 连线节点，配置每张卡片
4. 点击「运行」

## 依赖

- Obsidian ≥ 1.0.0
- 需要在插件设置中配置 AI API（兼容 OpenAI 格式）

## 开发

```bash
npm install
npm run dev    # 开发模式（watch）
npm run build  # 生产构建
```
